这一页讲两件事：**怎么让 AI 读懂这份文档**，以及**怎么把 x-iztro 接进 AI 应用**。

## 让 AI 读这份文档

### `/llms.txt`

站点结构索引，列出所有页面的标题、描述与链接。适合让模型先定位再抓取。

<Endpoint path="/llms.txt" />

### `/llms-full.txt`

全站文档的 Markdown 全文，一次抓取即可作为完整上下文。

<Endpoint path="/llms-full.txt" />

### 单页 Markdown

任意文档页 URL 追加 `.md` 就得到该页的 Markdown 原文：

<Endpoint path="/zh/docs/guide/guides/config.md" />

`.md` 与 `.mdx` 两种后缀都可以，返回内容相同。
页面标题下方的「复制 Markdown」按钮取的就是这个端点，「打开」下拉里还能
直接送进 ChatGPT 或 Claude。

### 不知道后缀约定也能拿到

AI 代理在请求任意文档页时，只要 `Accept` 头里表明更想要 Markdown，
就会拿到 Markdown 原文而不是整页 HTML：

```bash
curl -H "Accept: text/markdown" <本站地址>/zh/docs/rust/palace
```

同一个页面，HTML 约 400 KB，Markdown 约 14 KB。

<Callout>
这三个端点返回的都是纯文本，没有导航、样式与脚本，
比让模型抓 HTML 省 token 也更准确。
</Callout>

### 建议的用法

问 AI 关于 x-iztro 的问题时，把 `/llms-full.txt` 作为上下文一起给它。
全站文档的规模在常见模型的上下文窗口内绰绰有余。

如果只关心某个主题，抓对应的单页 `.md` 更省：

| 主题 | 页面 |
| --- | --- |
| 参数与安装 | `/zh/docs/guide/getting-started.md` |
| 领域概念 | `/zh/docs/guide/concepts.md` 及其子页 |
| 分界点与流派 | `/zh/docs/guide/guides/config.md` |
| 字段字典 | `/zh/docs/guide/data-model.md` |

## 把 x-iztro 接进 AI 应用

### 内置 Prompt 生成

库自带把命盘转成结构化文本的函数，不必自己拼描述：

```python
natal = astro.astrolabe_to_prompt(chart)
fortune = astro.horoscope_to_prompt(chart, "2024-10-1", 0)
```

输出格式与用法见 [AI Prompt 生成](/zh/docs/guide/guides/ai-prompt)。

### 用英文盘喂模型

命理术语的中文对模型不算难，但如果目标模型的中文能力一般，
可以用英文排盘，生成的 prompt 也会是英文：

```python
chart = astro.by_solar("2000-8-16", 2, "female", language="en-US")
prompt = astro.astrolabe_to_prompt(chart)   # 英文
```

排盘结果本身与语言无关，换语言不影响任何计算。

### 做成工具调用

排盘是确定性计算，很适合做成给模型调用的工具：模型负责理解需求与解读，
x-iztro 负责算准。一个最小的工具定义：

```python
{
    "name": "cast_chart",
    "description": "紫微斗数排盘。给定阳历生日、时辰索引与性别，返回完整命盘的结构化描述。",
    "input_schema": {
        "type": "object",
        "properties": {
            "solar_date": {"type": "string", "description": "阳历生日，格式 YYYY-M-D"},
            "time_index": {"type": "integer", "minimum": 0, "maximum": 12,
                           "description": "时辰索引，0=早子时(00-01)，12=晚子时(23-24)"},
            "gender": {"type": "string", "enum": ["male", "female"]},
        },
        "required": ["solar_date", "time_index", "gender"],
    },
}
```

实现里调 `astrolabe_to_prompt` 返回文本即可。

<Callout type="warn" title="别让模型自己排盘">
大模型算不准干支与安星 —— 它会给出看起来合理但错误的结果。
排盘交给库，模型只负责解读。
</Callout>

### 判断逻辑用 key

如果你的应用要基于盘的内容做分支（例如「命宫有化忌时走另一套话术」），
用[语言无关 key](/zh/docs/guide/guides/keys) 判断，不要匹配文本 ——
否则换一种输出语言，所有分支都会静默失效。
