## 最容易踩的三个坑

1. **用星名做判断**。换一种输出语言，所有分支静默失效。
   用 [key](/zh/docs/guide/guides/keys)。
2. **忽略晚子时**。23:00–24:00 出生要用时辰索引 `12` 而不是 `0`，
   两者排出的盘不同。见 [Config](/zh/docs/guide/guides/config#晚子时归属-day_divide)。
3. **宫位索引当成宫名顺序**。`palaces[0]` 是寅宫，不是命宫。
   见[十二宫](/zh/docs/guide/concepts/palaces)。
