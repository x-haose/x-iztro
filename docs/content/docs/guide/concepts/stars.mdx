每个宫位上的星耀分三个数组存放，另外还有四组「十二神」以单值形式挂在宫上。

## 主星 `major_stars`

十四颗主星，是解读命盘的骨架。它们按紫微与天府两个系列的规则安放，
十二宫里有的宫会有两颗，有的一颗都没有（称为**空宫**）。

| 紫微系 | 天府系 |
| --- | --- |
| 紫微 `ziweiMaj` | 天府 `tianfuMaj` |
| 天机 `tianjiMaj` | 太阴 `taiyinMaj` |
| 太阳 `taiyangMaj` | 贪狼 `tanlangMaj` |
| 武曲 `wuquMaj` | 巨门 `jumenMaj` |
| 天同 `tiantongMaj` | 天相 `tianxiangMaj` |
| 廉贞 `lianzhenMaj` | 天梁 `tianliangMaj` |
| | 七杀 `qishaMaj` |
| | 破军 `pojunMaj` |

`is_empty()` 判断的就是这个数组是否为空。

## 辅星 `minor_stars`

十四颗辅星，按性质分四类。`type` 字段给出类别：

| 类别 | `type` | 成员 |
| --- | --- | --- |
| 吉星 | `soft` | 左辅、右弼、文昌、文曲、天魁、天钺 |
| 煞星 | `tough` | 擎羊、陀罗、火星、铃星、地空、地劫 |
| 禄存 | `lucun` | 禄存 |
| 天马 | `tianma` | 天马 |

<Callout title="六煞与六吉">
`tough` 的六颗合称**六煞**，`soft` 的六颗合称**六吉**。
判断某宫「有没有煞」时按 `type` 过滤，不要按星名硬编码——
换语言后星名会变，`type` 不会。
</Callout>

## 杂耀 `adjective_stars`

数十颗辅助性质的星，按来源分成年干系、年支系、月系、日系、时系几类，安星依据各不相同。

杂耀里有三个 `type` 取值：

| 类别 | `type` | 数量 | 成员 |
| --- | --- | --- | --- |
| 桃花星 | `flower` | 4 | 红鸾、天喜、天姚、咸池 |
| 解神 | `helper` | 2 | 解神、年解 |
| 其余杂耀 | `adjective` | 32 | 三台、八座、天刑、天厨、天哭、天虚、孤辰、寡宿、龙池、凤阁、台辅、封诰、天官、天福、破碎、蜚廉、阴煞、天空、旬空、截空、天伤、天使等 |

<Callout type="warn" title="四化只看主星与辅星">
`has_mutagen()` 只检查 `major_stars` 与 `minor_stars`，**不检查杂耀**。
</Callout>

## StarType 的八个取值

上面三组加起来正好覆盖 `type` 的全部取值：

| `type` | 出现在哪一组 | 一句话 |
| --- | --- | --- |
| `major` | 主星 | 十四主星，定盘面骨架 |
| `soft` | 辅星 | 六吉 |
| `tough` | 辅星 | 六煞 |
| `lucun` | 辅星 | 禄存，单独成类 |
| `tianma` | 辅星 | 天马，单独成类 |
| `flower` | 杂耀 | 桃花星 |
| `helper` | 杂耀 | 解神 |
| `adjective` | 杂耀 | 其余杂耀 |

<Callout type="info" title="为什么禄存与天马要单拎出来">
它们在传统分法里既非纯吉也非纯煞：禄存主财禄但畏空劫，天马主动主变但需见禄。
判断时常要把它们与六吉六煞分开处理，因此各占一个 `type`，
用 `type == "lucun"` 就能直接筛出，不必按星名硬编码。
</Callout>

## 星耀字段

无论哪一组，单颗星的结构相同：

| 字段 | 含义 |
| --- | --- |
| `name` | 星名，按排盘语言翻译 |
| `key` | 语言无关标识，如 `ziweiMaj` |
| `type` | 类别：`major` / `soft` / `tough` / `adjective` / `flower` / `helper` / `lucun` / `tianma` |
| `scope` | 所属层级：`origin` 本命、`decadal` 大限、`yearly` 流年…… |
| `brightness` | 亮度，只有部分星有 |
| `mutagen` | 四化标记，只有被化到的星有 |

## 亮度

亮度描述一颗星落在某个地支位置上的强弱，共七级：

| 亮度 | key | 强弱 |
| --- | --- | --- |
| 庙 | `miao` | 最强 |
| 旺 | `wang` | |
| 得 | `de` | |
| 利 | `li` | |
| 平 | `ping` | 中性 |
| 不 | `bu` | |
| 陷 | `xian` | 最弱 |

同一颗星在不同宫位亮度不同，这是由星与地支的固定对照表决定的。
杂耀通常没有亮度，字段为空。

## 四组十二神

除了三组星耀数组，每个宫还挂着四个**单值**字段，各自来自一套十二神的循环安法：

| 字段 | 名称 | 依据 | 十二个成员 |
| --- | --- | --- | --- |
| `changsheng12` | 长生十二神 | 五行局与阴阳男女 | 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养 |
| `boshi12` | 博士十二神 | 禄存位置与阴阳男女 | 博士、力士、青龙、小耗、将军、奏书、飞廉、喜神、病符、大耗、伏兵、官府 |
| `suiqian12` | 岁前十二神 | 年支 | 岁建、晦气、丧门、贯索、官符、小耗、大耗、龙德、白虎、天德、吊客、病符 |
| `jiangqian12` | 将前十二神 | 年支三合 | 将星、攀鞍、岁驿、息神、华盖、劫煞、灾煞、天煞、指背、咸池、月煞、亡神 |

每个宫恰好各有一个，十二宫合起来正好是一整轮。

```python
for p in chart.palaces:
    print(p.name, p.changsheng12, p.boshi12, p.suiqian12, p.jiangqian12)
```

<Callout>
运限层级还会带自己的岁前十二神与将前十二神
（流年的 `yearly_dec_star.suiqian12` / `jiangqian12`），
它们按运限年支重新起算，与本命盘上的这四组是两回事。
见[运限](/zh/docs/guide/concepts/horoscope)。
</Callout>

## 查一颗星在哪

```python
from x_iztro.enums import MajorStar

star = chart.star(MajorStar.ZIWEI)
print(star.name, star.brightness, star.mutagen)
```

```go
star, palace := chart.Star(iztro.StarZiweiMaj)
fmt.Println(palace.Name, star.Brightness)
```

```rust
if let Some((star, palace)) = astrolabe.star(StarKey::ZiweiMaj) {
    println!("{:?} {:?}", palace.name, star.brightness);
}
```

查找会遍历三组数组，所以主星、辅星、杂耀都能查到。
