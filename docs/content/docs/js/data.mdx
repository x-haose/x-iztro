---

表是排盘的输入，与输出语言无关；取值一律为语言无关标识。

```ts
data.starsInfo(): Record<string, StarInfo>;              // 十四主星与昌曲火铃羊陀共 20 颗
data.heavenlyStems(): Record<HeavenlyStem, HeavenlyStemInfo>;
data.earthlyBranches(): Record<string, EarthlyBranchInfo>;
data.constants(): Constants;                             // 语言、干支、生肖、星座、宫名、五虎遁、五鼠遁……
data.flowStarCounterparts(): Record<string, string>;     // 流耀 → 本命辅星，50 条
```

```js
console.log(data.starsInfo().ziweiMaj, data.heavenlyStems().gengHeavenly, data.earthlyBranches().wuEarthly);
const c = data.constants();
console.log(c.languages, c.fiveElementsClass, Object.keys(data.flowStarCounterparts()).length, data.flowStarCounterparts().liulu);
```

## 枚举清单

每个枚举既是常量对象（`MajorStar.ZIWEI`），又是同名的取值联合类型（`MajorStar`）。从 `x-iztro` 或不含内核的 `x-iztro/types` 导入都可以。

| 枚举 | 取值 |
| --- | --- |
| `Gender` | `male` `female` |
| `Language` | `zh-CN` `zh-TW` `en-US` `ja-JP` `ko-KR` `vi-VN` |
| `Algorithm` / `AstroType` | `default` `zhongzhou` / `heaven` `earth` `human` |
| `YearDivide` / `HoroscopeDivide` / `AgeDivide` / `DayDivide` / `VoidPlacement` / `LeapDivide` / `TianmaPlacement` / `ChangshengDirection` / `TianshangTianshi` / `TianwuPlacement` / `Yearly12Placement` / `OriginalPalaceMarking` / `DouJunMonth` / `DecadalStem` / `ChildhoodPalace` / `AgeMutagens` / `YearlyPalace` / `ScopeMutagenStem` / `MonthlyPalace` / `DailyPalace` / `LeapDaily` / `HourlyPalace` | 见 [ChartConfig](/zh/docs/js/astro#chartconfig) |
| `HeavenlyStem` / `EarthlyBranch` | `jiaHeavenly` … `guiHeavenly` / `ziEarthly` … `haiEarthly` |
| `PalaceName` | 十二宫名，另有 `BODY`（`bodyPalace`）与 `ORIGINAL`（`originalPalace`）供定位 |
| `FiveElementsClass` | `water2nd` `wood3rd` `metal4th` `earth5th` `fire6th`；局数见常量 `FIVE_ELEMENTS_CLASS_NUMBER` |
| `Mutagen` | `sihuaLu` `sihuaQuan` `sihuaKe` `sihuaJi`；固定顺序见常量 `MUTAGEN_ORDER` |
| `Brightness` | `miao` `wang` `de` `li` `ping` `bu` `xian`，外加 iztro 没有的 `xian2`（闲）与 `di`（地），只出现在自定义亮度表里 |
| `StarType` / `Scope` / `MonthPart` | 星耀类型 / 层级 / 流月分段 |
| `MajorStar` / `MinorStar` / `AdjectiveStar` / `HoroscopeStar` | 全部 164 个星耀标识 |
| `Changsheng12` / `Boshi12` / `Suiqian12` / `Jiangqian12` | 四组十二神 |
| `PatternKey` | 64 个格局标识 |
| `BrightnessSource` / `TextDetail` / `KnowledgeDepth` | 格局判定与文本选项 |

`TimeIndex` 是 `0 | 1 | … | 12` 的类型。
