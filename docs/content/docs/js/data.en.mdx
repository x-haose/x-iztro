title: Data tables
description: The data module's star and stem/branch tables, ordering constants and horoscope-star mapping, plus every enum.
---

The tables are charting input and do not depend on the output language; every value is a language-independent key.

```ts
data.starsInfo(): Record<string, StarInfo>;              // the 14 major stars plus Wenchang, Wenqu, Huoxing, Lingxing, Qingyang, Tuoluo
data.heavenlyStems(): Record<HeavenlyStem, HeavenlyStemInfo>;
data.earthlyBranches(): Record<string, EarthlyBranchInfo>;
data.constants(): Constants;                             // languages, stems, branches, zodiac, signs, palace names, tiger and rat rules …
data.flowStarCounterparts(): Record<string, string>;     // horoscope star → natal minor star, 50 entries
```

```js
console.log(data.starsInfo().ziweiMaj, data.heavenlyStems().gengHeavenly, data.earthlyBranches().wuEarthly);
const c = data.constants();
console.log(c.languages, c.fiveElementsClass, Object.keys(data.flowStarCounterparts()).length, data.flowStarCounterparts().liulu);
```

Entries left blank in the source table are `null` (the five elements of Taiyang, Qisha and six minor stars, the
yin-yang of some stars, and the clashing stem of Wu and Ji).

## Enum list

Every enum is both a constant object (`MajorStar.ZIWEI`) and a union type of its values under the same name
(`MajorStar`). Import them from `x-iztro` or from the core-free `x-iztro/types`.

| Enum | Values |
| --- | --- |
| `Gender` | `male` `female` |
| `Language` | `zh-CN` `zh-TW` `en-US` `ja-JP` `ko-KR` `vi-VN` |
| `Algorithm` / `AstroType` | `default` `zhongzhou` / `heaven` `earth` `human` |
| `YearDivide` / `HoroscopeDivide` / `AgeDivide` / `DayDivide` / `VoidPlacement` | See [ChartConfig](/en/docs/js/astro#chartconfig) |
| `HeavenlyStem` / `EarthlyBranch` | `jiaHeavenly` … `guiHeavenly` / `ziEarthly` … `haiEarthly` |
| `PalaceName` | The twelve palace names, plus `BODY` (`bodyPalace`) and `ORIGINAL` (`originalPalace`) for locating |
| `FiveElementsClass` | `water2nd` `wood3rd` `metal4th` `earth5th` `fire6th`; the numbers are in `FIVE_ELEMENTS_CLASS_NUMBER` |
| `Mutagen` | `sihuaLu` `sihuaQuan` `sihuaKe` `sihuaJi`; the fixed order is `MUTAGEN_ORDER` |
| `Brightness` | `miao` `wang` `de` `li` `ping` `bu` `xian`, plus `xian2` (闲), which iztro lacks and which only appears in custom brightness tables |
| `StarType` / `Scope` / `MonthPart` | Star type / layer / monthly segment |
| `MajorStar` / `MinorStar` / `AdjectiveStar` / `HoroscopeStar` | All 164 star keys |
| `Changsheng12` / `Boshi12` / `Suiqian12` / `Jiangqian12` | The four twelve-spirit cycles |
| `PatternKey` | The 64 pattern keys |
| `BrightnessSource` / `TextDetail` / `KnowledgeDepth` | Pattern and text options |

`TimeIndex` is the type `0 | 1 | … | 12`.
